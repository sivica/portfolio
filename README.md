# Ivica Stojanoski — Personal Portfolio

Senior Android / Kotlin–Compose portfolio for Ivica Stojanoski. Single-page home with case-study routes for Widex companions, Premier League, and MovieApp.

## Stack

- Next.js (App Router) + TypeScript
- Tailwind CSS v4
- shadcn/ui

## Run locally

```bash
npm install
npm run dev -- --port 43127
```

Open [http://127.0.0.1:43127](http://127.0.0.1:43127).

## Scripts

| Command | Description |
|---|---|
| `npm run dev` | Development server |
| `npm run build` | Production build |
| `npm run start` | Serve production build |
| `npm run lint` | ESLint |
